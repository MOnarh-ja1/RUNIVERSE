# RUNIVERSE 3.3.0 — редактируемый проект Godot

Это **новый исходный проект**, написанный для исправления главной проблемы старого EXE:
портреты изменялись в магазине, но во время бега использовались старые модели.

В проекте `scripts/runiverse_v33.gd` выполняется реальная загрузка `GLTFDocument`
и `GLTFState` из `res://assets/models/*.glb` для первых 15 персонажей.
Повороты рук/ног вокруг точек плеч и бёдер создают анимации бега,
прыжка и подката. При выборе персонажа в магазине сохраняется ID `selected`,
который напрямую передаётся в `_spawn_hero()` при старте забега.

Проект можно открывать в Godot 4.7 или более новой версии Godot 4.
Эта реконструкция не включает зашифрованный оригинальный GDScript; исходные
50 имён, цен и бонусов сохранены в `data/characters.json`.

Старые сохранения не перезаписываются. Новый формат — `user://runiverse_v33_save.json`.
Проверены форматы ресурсов, но не проведён нативный запуск на Windows.
