# RUNIVERSE — MgameIO

Это репозиторий проекта RUNIVERSE — 3D endless runner для Windows, созданного на Godot.

## Состояние
Подключаем исходный проект RUNIVERSE 3.3.0 и систему обновлений через MgameIO Launcher.

**Важно:** исходный проект переносится по частям; до загрузки `scripts/runiverse_v33.gd` и ресурсов из `assets/` он не готов к сборке.

## План публикации
- Исходный код и 3D-модели
- Сборка Windows через GitHub Actions
- Публикация версий и `manifest.json`
- Загрузка обновлений из MgameIO Launcher
