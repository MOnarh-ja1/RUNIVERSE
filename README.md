# RUNIVERSE 3.3.0 — MgameIO

Исходный проект 3D-раннера RUNIVERSE для Godot 4.7, редакция 3.3.0. Это реконструированная версия игры, а не восстановленные оригинальные зашифрованные скрипты прежнего EXE.

## Что здесь находится

- `project.godot`, `boot.tscn` — конфигурация и главная сцена
- `scripts/runiverse_v33.gd` — игровой код: меню, магазин, забег, миры, рекорды
- `data/characters.json` — 50 персонажей, цены и бонусы
- `assets/models/` — 15 мультяшных моделей GLB для первых 15 героев
- `assets/portraits/` — 50 изображений персонажей
- `assets/` — дополнительные ресурсы и иконки

## Запуск в Godot

1. Установите Godot 4.7 (или совместимую версию 4.x).
2. Откройте папку проекта в Godot через **Import** и выберите `project.godot`.
3. Дождитесь импорта GLB-ресурсов, затем запустите главную сцену.

## Обновления в лаунчере

Планируем использовать GitHub Actions для Windows-экспорта, GitHub Releases для хранения обновлений и HTTP(S)-манифест версий для MgameIO Launcher. Это пока **не настроено**: текущий репозиторий содержит исходники, а не готовый автоматический выпуск обновлений.

## Примечания

Старые сохранения не удаляются, но автоматический перенос из оригинальной 3.2 не гарантируется. Новый файл прогресса: `user://runiverse_v33_save.json`.

Исходники и ресурсы перенесены полностью (15 моделей GLB и 50 портретов). Запуск игры на настоящем Windows-ПК на данном этапе не проверен.
