# MgameIO Launcher 1.1 — Google вход и мировой ТОП

Готовый исходный код Windows лаунчера поддерживает:
- OAuth Google в системном браузере с PKCE, state и loopback redirect.
- Проверку ID token на RUNIVERSE сервере; пароль Google не запрашивается лаунчером.
- Профиль, лучший результат, количество забегов и мировой TOP-100.
- Общий Google-аккаунт для игры и лаунчера, когда обе программы подключены к одному API.

Текущий статус: **не активировано на публичном сервере**. Поля в `online/public_config.json` пусты специально. До их настройки нельзя отображать рейтинг как реальный и заявлять об успешной авторизации.

Что требуется владельцу:
1. В Google Cloud Console настроить OAuth consent screen и OAuth client типа Desktop; разрешить нужные тестовые аккаунты или пройти публикацию/проверку приложения, если требуется. Получить client ID (это не пароль).
2. Развернуть `online/server` на постоянном HTTPS-хостинге, задать `GOOGLE_CLIENT_ID`, секреты/настройки БД и защитить сайт от накруток. SQLite на эфемерном диске нельзя использовать как постоянную базу.
3. Заполнить **публичный** `online/public_config.json` полями `api_base` и `google_client_id`. Никогда не помещать OAuth client secret, пароли или API-токены в этот JSON.
4. Синхронизировать интеграцию игры с тем же backend и протестировать на Windows.

Изменение данных публичного конфига не требует переустановки нового лаунчера — он загружает их с GitHub при каждом входе и открытии топа.

Ограничения текущего клиента: токен хранится только в памяти до закрытия приложения; после перезапуска понадобится повторный вход. Для долговременного сохранения рекомендуется Windows DPAPI / Credential Manager.

Старый MgameIO Launcher 1.0.8 не умеет менять свой собственный интерфейс по каталогу игр: один раз нужно установить версию 1.1.0, чтобы появились вкладки профиля и топа.
